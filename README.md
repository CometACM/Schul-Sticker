# Schul-Sticker
Die Sammel-Sticker (Bilder im PNG Format) sind nur für die *private Nutzung* im Unterricht, 
z.B. zum Schmücken eurer Texte (z.B. für GoodNotes, Pages) oder im Klassen-Chat. 

#### Bitte keine kommerzielle Nutzung oder Weitergabe!
#### Die Sticker sind exklusiv für euch und eure eigenen Geräten wie iPads oder Handys.
